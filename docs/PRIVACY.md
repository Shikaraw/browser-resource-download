# 隐私说明

## 一句话

**扩展不上传任何数据。扫描只在你点击按钮后发生。**

## 数据流

```
用户点击「扫描本页资源」
        │
        ▼
popup ──SCAN_PAGE──▶ background ──executeScript──▶ 页面内 scanner.js
        │                                               │
        │◀──────── ScanResult（资源列表）───────────────┘
        ▼
    渲染列表（仅本地内存）

用户勾选后点击「下载选中」
        │
        ▼
background ──chrome.downloads──▶ 浏览器原生下载 → 本地磁盘
```

* **没有任何请求发往第三方服务器。**
* 扩展不包含远程代码、不加载 `eval`、不引入第三方 SDK 或统计脚本。
* 资源 URL 仅存在于 popup 页面内存与（可选）最近扫描摘要中，摘要**不保存资源 URL**。

## 权限用途

| 权限 | 用途 |
|---|---|
| `activeTab` | 用户点击图标时，仅获得**当前标签页**的临时访问权。 |
| `scripting` | 在用户点击后注入扫描器（`content/scanner.js`）。 |
| `downloads` | 调用浏览器原生下载保存资源。 |
| `storage` | 保存你的设置与最近扫描摘要，仅本地。 |
| `contextMenus` | 提供右键「扫描本页的资源…」（可关闭）。 |
| `notifications` | 下载完成提示（可关闭）。 |
| `host_permissions: <all_urls>` | 扫描器需要在任意站点工作。**但脚本只在用户点击时才注入**。 |

## 关键设计约束

1. **零自动采集**：`manifest.json` 中**没有** `content_scripts` 声明，
   页面加载时扩展完全不接触页面内容。扫描器只在 `SCAN_PAGE` 消息到达时
   （即用户点击按钮）通过 `chrome.scripting.executeScript` 注入。
2. **扫描可取消**：扫描过程中随时可点击「取消」，扫描器立即停止收集。
3. **不记录敏感信息**：不保存表单内容、输入、Cookie、请求头。
4. **不上报错误**：错误只显示在 UI 上，不发送到任何地方。

## 你的控制权

* 设置页「数据与隐私」中可一键**清空扫描历史**或**恢复默认设置**。
* 卸载扩展即删除全部本地数据（`chrome.storage.local` 随之清除）。
